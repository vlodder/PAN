#  PAN - GEIPAN Observation Platform

> Cross-platform mobile application developed in **.NET MAUI** for collecting, managing and analysing unidentified aerial phenomena (UAP/PAN) reports.

---

##  Overview

PAN is a cross-platform mobile application built as part of a software engineering project.

The application allows users to report unidentified aerial phenomena (UAP), browse existing reports and interact with observations through a modern mobile interface.

The project demonstrates software engineering best practices including:

- MVVM architecture
- Entity Framework
- SQL Server
- Cross-platform development with .NET MAUI
- CRUD operations
- Clean project architecture

---

##  Features

### User

- Create a new observation
- Edit an existing observation
- Browse reports
- Search observations
- View observation details
- Upvote reports

###  Observation information

Each report includes:

- Observation date
- Description
- Geographic location
- Moving / Static object
- Object category
- Popularity (Upvotes)

###  GEIPAN Investigator

- Review observations
- Add investigation reports
- Classify phenomena
- Assign phenomenon type
